# PnP-Combat

## Grundidee

- Web-Applikation um Kämpfe in Dungeon-And-Dragon zu planen und zu koordinieren
- Vor dem Kampf legt der DM fest, welche Monster und Spielerfiguren beteiligt sind
- Die Monster bekommen ihre HP und allfällige modifikationen können hinterlegt werden
- Die Spielerfiguren bekommen ihre HP und allfällige modifikationen können hinterlegt werden
- Die Intitiaive wird vor dem Kampf festgelegt
- bei gleichstand der Initiave gilt der Geschicklichkeits-Modifikator
- Beim Start des Kampfes wird automtisch die Reihenfolge anhand der Initiave festgelegt
- Schaden kann direkt eingetragen werden und der wird von der HP abgezogen
